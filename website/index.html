Thread-first workspace

Start every workflow in one conversation

Upload a spec, attach RTL, or pick a starter block — UART, FIFO, or bring your own design. The agent plans, edits, and verifies from the same thread. No tab hopping between chat, logs, and file trees.

  • Adaptive starter chips for greenfield design or existing RTL
  • Full history per project — every decision stays in context
  • ⌘K command palette to jump to files, runs, and actions

Mental model

Know what the agent thinks before it runs checks

Chipix builds a living understanding of your design from spec and RTL. Verification strategies and tests are planned from that map — not from generic codegen.

  • Required checkpoint before verification runs
  • Hierarchy graph + plain-English summary
  • Updates when you edit code in the IDE

Staged verification

Plan, approve, then run — safely

Flip to Verify mode when you're ready. Chipix recommends strategies (unit sim, formal, UVM), drafts a test plan for your approval, then executes locally on your toolchain.

  • Prepare → recommend → plan → execute (not fire-and-forget)
  • Diff cards with human approval gates
  • Dashboard for runs, KPIs, and failures
