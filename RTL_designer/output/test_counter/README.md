### Functional Description
This module implements a parameterizable, synchronous up-counter with load capability.

1.  **Reset:** On the rising edge of `clk_i`, if `rst_n_i` is asserted (low), the counter's internal state and the `count_o` output are reset to `0`. The reset is synchronous.

2.  **Load:** On the rising edge of `clk_i`, if `rst_n_i` is de-asserted and `load_i` is asserted, the counter is loaded with the value from `load_val_i`. The load operation has priority over the count enable.

3.  **Count:** On the rising edge of `clk_i`, if `rst_n_i` is de-asserted, `load_i` is de-asserted, and `en_i` is asserted, the counter increments its current value by the `INCREMENT` parameter. The counter will wrap around to `0` (or near `0`) upon reaching its maximum value.

4.  **Hold:** If `rst_n_i` is de-asserted and both `load_i` and `en_i` are de-asserted, the counter holds its current value.

5.  **Rollover Output:** The `rollover_o` signal is a single-cycle pulse. It is asserted in the same clock cycle that the counter reaches its maximum value while the enable is active, indicating that a rollover will occur on the *next* clock edge. For example, with `INCREMENT=1`, `rollover_o` is high when `count_o` is all ones and `en_i` is high.
