### Functional Description
This module implements a synchronous, parameterizable N-bit binary up/down counter.

**Reset:**
When the `arst_n` signal is asserted (low), the counter is immediately and asynchronously reset. The `count_out` value is forced to `0` and the `overflow` flag is de-asserted.

**Operation:**
On the positive edge of `clk`, if the `en` signal is high, the counter's value is updated based on the `up_down` signal.
- If `up_down` is high (1), the counter increments (`count_out` <= `count_out` + 1).
- If `up_down` is low (0), the counter decrements (`count_out` <= `count_out` - 1).

If the `en` signal is low, the counter holds its current value.

**Wrap-Around:**
The counter wraps around upon reaching its boundary conditions.
- When counting up, incrementing from the maximum value (`2^WIDTH - 1`) will result in `0`.
- When counting down, decrementing from `0` will result in the maximum value (`2^WIDTH - 1`).

**Overflow Flag:**
The `overflow` output signal is a synchronous flag that asserts for a single clock cycle to indicate that a wrap-around condition is about to occur.
- It will be asserted if `en` is high, `up_down` is high, and `count_out` is at its maximum value (`2^WIDTH - 1`).
- It will also be asserted if `en` is high, `up_down` is low, and `count_out` is `0`.
In all other conditions, `overflow` will be low.
