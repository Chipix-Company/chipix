### Functional Description
This module implements a parameterizable N-bit synchronous binary up/down counter.

-   **Reset:** When the asynchronous active-low reset `i_arst_n` is asserted (low), the counter output `o_count` is immediately forced to zero.
-   **Counting:** On each positive edge of `i_clk`, if `i_enable` is high, the counter value is updated.
    -   If `i_up_down` is high (1), the counter increments (`o_count` = `o_count` + 1).
    -   If `i_up_down` is low (0), the counter decrements (`o_count` = `o_count` - 1).
-   **Hold:** If `i_enable` is low, the counter holds its current value on the next positive clock edge.
-   **Overflow:** The `o_overflow` flag is a combinatorial output that asserts for one clock cycle under the following conditions:
    -   The counter is at its maximum value (all 1s), `i_enable` is high, and `i_up_down` is high (will wrap to 0).
    -   The counter is at its minimum value (0), `i_enable` is high, and `i_up_down` is low (will wrap to max value).
