# Keyboard shortcuts

Shortcuts use **⌘** on macOS and **Ctrl** on Windows/Linux.

## Global

| Shortcut | Action |
| --- | --- |
| **⌘K** / **Ctrl+K** | Open command palette (files, runs, projects, actions) |
| **⌘⇧E** / **Ctrl+Shift+E** | Open IDE workspace |
| **Escape** | Close the topmost overlay (palette, History panel, docs, dashboard, mental model, editor, clarifier) |

## Composer

| Shortcut | Action |
| --- | --- |
| **⌘Enter** / **Ctrl+Enter** | Send message |

When the **Design / Verify** toggle is focused, **←**, **→**, **Space**, and **Enter** switch modes.

## Single-file editor (file peek)

| Shortcut | Action |
| --- | --- |
| **⌘S** / **Ctrl+S** | Save file |
| **Escape** | Back to conversation (when no higher overlay is open) |

## IDE workspace

| Shortcut | Action |
| --- | --- |
| **⌘S** / **Ctrl+S** | Save active file |
| **Escape** | Close IDE (if nothing else is open) |

## Command palette

While the palette is open:

| Shortcut | Action |
| --- | --- |
| **↑** / **↓** | Move selection |
| **Enter** | Open selected item |
| **Escape** | Close palette |

## Documentation overlay

| Shortcut | Action |
| --- | --- |
| **Escape** | Close documentation |

## Command palette actions

Common entries (type to filter):

- Start a new project
- Start a new conversation
- Open IDE workspace
- Show mental model
- Start verification on active design
- Plan then verify (staged)
- Open dashboard
- Open documentation
- Take the workspace tour

## Side rail

Most navigation uses the left icon rail (Editor, Mental model, Staged flow, Task board, Dashboard). There are no separate keyboard shortcuts for every icon — use the palette when you prefer the keyboard.

## Tips

- If **⌘K** does nothing, close the clarifier or an open editor first — the palette is suppressed while those surfaces have focus.
- **Theme** toggle is on the left side rail (sun/moon); your choice is remembered on this device.
- **Sound** toggle is on the status bar at the bottom.

See [Workspace layout](workspace-layout.md) for where each surface lives in the UI.
